# social-publishing

Plan, create and publish or schedule social posts once the user approves the exact copy and media, then verify each post went out.

## What it does

- Plans content for the right account, audience, goal and time.
- Creates the media and copy, adapted to each network (format, aspect ratio, caption length, hashtags, alt text).
- Gets approval for the exact post before anything is published or scheduled.
- Publishes and verifies: waits for media processing, reads the post back after publication, and returns the live link (or scheduled time).

## Install

Copy this folder into your agent skills directory (for example `~/workspace/custom-skills/social-publishing/`), or install it from [skills.sh](https://www.skills.sh/).
